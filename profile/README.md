# net-merge

Use all your internet connections at once. Wi-Fi, Ethernet, mobile data and phone tethers share the load, so downloads get faster and one slow link does not hold you back.

It runs on Windows, macOS, Linux and Android. It is free and open source (MIT). There is no account and no server.

- **[net-merge](https://github.com/net-merge/net-merge)**: the app for Windows, macOS and Linux
- **[android](https://github.com/net-merge/android)**: the Android app
- **[website](https://github.com/net-merge/website)**: the source of [net-merge.org](https://net-merge.org)
- **[homebrew-tap](https://github.com/net-merge/homebrew-tap)**: `brew install net-merge/tap/net-merge`

Start at [net-merge.org](https://net-merge.org) to install it. Found a problem? [Open an issue](https://github.com/net-merge/net-merge/issues/new/choose). Questions: hello@net-merge.org.
